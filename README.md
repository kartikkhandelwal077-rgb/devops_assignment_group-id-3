# DevOps Assignment

Repository for DevOps Assignment submissions.

## Repository Structure

```
DevOpsAssignment
├── README.md
├── PPT/
├── Notes/
├── CheatSheet/
├── ReferenceVideo/
├── Images/
├── Assignment/
└── WeeklyTask/
```

### Directory Overview:
- **`PPT/`**: Contains presentation slide decks and relevant PowerPoint files.
- **`Notes/`**: Lecture notes, documentation, and reference materials.
- **`CheatSheet/`**: Command cheat sheets and quick reference guides.
- **`ReferenceVideo/`**: Links, scripts, or materials related to reference videos.
- **`Images/`**: Diagrams, screenshots, and visual documentation.
- **`Assignment/`**: Main assignment sub-folder for code and report submissions.
- **`WeeklyTask/`**: Weekly task files, updates, and progress logs.
